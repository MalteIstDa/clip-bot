# ClipBot: Watchlist, Best-ofs, mehrere Konten, Zeitplan, Sprachen, Galaxie-Design

Stand: 16.11.2026 · Wünsche von Malte

| Wunsch | Umsetzung |
|---|---|
| Clips zusammensetzen (tägliche/wöchentliche Best-ofs, 1–2 Minuten) | Beim Clippen werden zusätzlich kurze „Momente“ (8–22 s) gespeichert. `clipbot/bestof.py` wählt daraus die besten über mehrere Creator, rendert sie einzeln und hängt sie zu einem Video zusammen. |
| Creator im Clip taggen (Text oben, z. B. „Gtastys unglaublicher Stunt“) | Die Hook-Zeile nennt den Creator beim Namen und bleibt wahlweise die ganze Zeit stehen (`creator_tag`, `hook_seconds`). In Best-ofs hat jeder Abschnitt seine eigene Zeile. |
| Liste mit vielen YouTubern/Streamern, Reminder bei Live/Upload, automatisches Clippen | Neue Watchlist (`creators` in `config.yaml`), `clipbot/watch.py` prüft YouTube (RSS-Feed + yt-dlp), Twitch und andere Seiten. Reminder im Dashboard, als Mitteilung des Betriebssystems und optional aufs Handy (ntfy, Discord). Neue Videos und beendete Streams landen in einer Warteschlange und werden automatisch geclippt. |
| Upload nur zu bestimmten Uhrzeiten | `upload_times` (allgemein) und eigene Zeiten je Konto. Die Automatik lädt je Konto und Uhrzeit einen freigegebenen Clip hoch. |
| 4–8 TikTok-/YouTube-Konten verwalten | Konten sind eigene Einträge (`accounts`), nicht mehr fest an einen Kanal gebunden. Neuer Bereich „Konten“ im Dashboard. |
| Mehrere Quellen und mehrere Upload-Konten verknüpfen | Ein Kanal verbindet beliebig viele Creator mit beliebig vielen Konten. Uploads werden je Konto gemerkt (`posts`). Wahlweise bekommt jedes Konto jeden Clip oder die Clips werden abwechselnd verteilt. |
| Deutsch, Französisch, Polnisch, Amerikanisch | Sprache je Kanal (`de`, `en`, `fr`, `pl`): KI-Texte, feste Textbausteine (Credit, Best-of-Titel) und Erklärvideos in dieser Sprache. |
| Dashboard dunkel, modern, Galaxie mit animierten Sternen | Neues Design: scharf gerenderter Sternenhimmel (Canvas in Gerätepixeln), Nebel, Spiralgalaxie, Sternschnuppen; Glas-Flächen, neue Bereiche Watchlist und Konten. |

## Datenmodell

```yaml
accounts:            # Upload-Konten
  - {id: yt_main, platform: youtube, label: DailyN3ONClipZ, token_file: tokens/yt_main.json, times: ""}
creators:            # Watchlist
  - {id: n3on, name: N3on, url: https://www.youtube.com/@N3on, notify: true, auto_clip: true}
channels:            # verbindet Creator mit Konten
  - {name: n3on, kind: clips, language: en, creators: [n3on], accounts: [yt_main], clips: true, bestof: "off", distribute: alle}
```

Alte Konfigurationen (`source_url`, `upload`, `caption_language`) werden beim Laden automatisch umgestellt; Token-Dateien bleiben, wo sie sind.

## Automatik

Ein Hintergrund-Takt im Dashboard (`clipbot/auto.py`):

1. Watchlist prüfen (läuft immer, auch während ein Auftrag arbeitet) → Reminder, neue Videos in die Warteschlange.
2. Wenn „Automatik“ an ist und gerade kein Auftrag läuft: fällige Uploads → wartende Videos clippen → fällige Best-ofs bauen.

`require_approval` und `dry_run` gelten weiter: Ohne Freigabe geht nichts online, im Testmodus lädt die Automatik nichts hoch.

## Reihenfolge

1. Grundlage: `config.py` (Konten, Creator, Sprachen, Umstellung), `state.py` (posts, moments, notifications, watch), `lang.py`.
2. `sources.py`, `watch.py`, `notify.py`.
3. `schedule.py`, `auto.py`.
4. `bestof.py`, Creator-Tag in `viral.py`/`subtitles.py`.
5. `app.py`-Schnittstellen, Dashboard neu.
6. Tests (Fake-Quellen, Fake-KI, echtes ffmpeg), README.
