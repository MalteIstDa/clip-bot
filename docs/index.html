ClipBot

A personal desktop tool for clippers.

ClipBot runs on the user's own computer. It turns livestreams and videos of creators the user follows into short vertical clips with subtitles and lets the user publish them to their own TikTok and YouTube accounts. Clips are only taken from creators who allow it, for example through an official clipping campaign.

How it uses TikTok

  • The user connects their own TikTok account with TikTok Login Kit and grants the video.publish permission.
  • ClipBot shows the clip, its caption and the privacy setting in its local dashboard. The user decides what is posted.
  • The clip is uploaded to the user's account through the TikTok Content Posting API.
