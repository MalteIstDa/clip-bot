Privacy Policy

Last updated: November 20, 2026

ClipBot is software that runs locally on the user's own computer. There is no ClipBot server, and the developer of ClipBot does not receive any data.

What is stored

  • Access tokens for the TikTok and YouTube accounts the user connects. They are stored only on the user's computer (folder tokens/) and are used only to publish the user's clips.
  • Videos, clips, captions and settings created by ClipBot, also only on the user's computer.

What is sent to third parties

  • TikTok: the clip and its caption when the user publishes, plus the basic account information needed for the upload (video.publish).
  • Google (YouTube Data API): the clip, title and description when the user publishes to YouTube.
  • Optional: transcripts of a clip to the AI service the user selects (Anthropic Claude or a local model) to write titles and captions.

ClipBot does not sell data, does not show ads and does not track users.

Deleting data

Disconnect the account in the ClipBot dashboard or delete the tokens/ folder. Access can also be revoked at any time in the TikTok app under Settings → Security → Manage app permissions.
